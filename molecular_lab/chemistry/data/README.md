# Element reference data

`elements.json` contains atomic number, symbol, and English element name for the 118 officially named elements.

This is identity/reference data only. It does not encode oxidation states, valence, bonding rules, stability, abundance, or physical properties. Such data must be added as separately sourced datasets with explicit provenance.
